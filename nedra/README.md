# Недра: шахта-рогалик

Игра по [GDD.md](GDD.md). Сейчас это вертикальный срез **v0.1**: пласты 1-3 с тремя Разломами, мета-прогрессия, реклама и покупки Яндекс Игр.

Стек: TypeScript + Vite + Canvas 2D, без движка и внешних ассетов (пиксель-арт и звук генерируются кодом). Сборка весит около 150 КБ, грузится мгновенно даже на слабых телефонах.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173, реклама и покупки имитируются
npm test           # 50 тестов: генерация, физика, забег, бот проходит все типы ярусов
npm run build      # сборка в dist/
```

Параметры адреса для отладки: `?fastads` (тестовая реклама без задержки), `?debug` (объект `window.__game` в продакшен-сборке), `?platform=dev` (не грузить SDK Яндекса).

Управление: держи палец или мышь там, куда копать; на ПК стрелки или WASD, 1-3 и пробел для расходников, Esc для паузы.

## Публикация на Яндекс Играх

1. `npm run build`, затем заархивировать **содержимое** `dist/` (index.html в корне архива) и загрузить в [консоль](https://games.yandex.ru/console/).
2. SDK подключается сам с `/sdk.js` (так площадка требует для игр, загруженных архивом). Вне Яндекса игра автоматически переходит в тестовый режим.
3. В консоли создать товары с такими ID (все постоянные, не потребляются):
   - `no_ads` - Без рекламы
   - `starter_pack` - Набор новичка (300 слитков и золотая каска)
   - `golden_smelter` - Золотая плавильня (+50% слитков)
4. Лидерборд с техническим именем `depth` (рекорд глубины в метрах).
5. Remote Config, флаг `ad_cooldown`: минимальная пауза между полноэкранной рекламой в секундах (по умолчанию 150). Частоту дополнительно ограничивает сама площадка.
6. Sticky-баннер включается в консоли. На мобильных внизу HUD оставлено место под расходники; если баннер мешает, включить управление баннером через API.

Где вызывается реклама:

- полноэкранная: переход на следующий ярус со станции и выход из итогов в посёлок; не раньше первого подъёма с добычей и не чаще `ad_cooldown`;
- rewarded: «Второе дыхание», x2 слитков в итогах, ещё вариант артефакта, бесплатный переброс на Ярмарке, новые наследники.

## RuStore

Игра собирается как веб-приложение, поэтому для Android её нужно обернуть (например, Capacitor) и заменить `src/platform/yandex.ts` на реализацию интерфейса `Platform` (`src/platform/types.ts`) для Android:

- платежи: RuStore Pay SDK (официально есть для Kotlin/Java, Unity, Godot, Defold; для обёртки нужен небольшой нативный плагин-мост);
- реклама: Yandex Mobile Ads SDK (полноэкранная, rewarded, баннер);
- сохранения: локальные (уже работают через localStorage WebView).

## Структура

```
src/
  config.ts           баланс (числа из GDD)
  core/               логика без отрисовки: генерация, физика, забег, экономика, сохранения
  data/               пласты, руды, артефакты, профессии, черты, события, постройки
  game/               сцена яруса, текстуры, звук, ввод, контроллер игры
  ui/                 HUD и экраны (DOM)
  platform/           Яндекс Игры и тестовая заглушка
tests/                модульные тесты и бот
pacing_sim.py         модель темпа прогрессии (30-40 часов)
```

## Баланс

- `python3 pacing_sim.py` - сколько часов до каждого Разлома при текущих формулах.
- `tests/bot.ts` - бот, который проходит ярусы. Замер на текущем балансе (пласт 1, без улучшений): ярус стоит около 35-45 энергии при старте 100 и даёт 50-70 монет. Человек тратит больше, так что первый забег доходит до 2-3 яруса, как задумано. Финальные цифры подбирать по метрикам после релиза.
