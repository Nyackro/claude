# Недра: шахта-рогалик

Игра по [GDD.md](GDD.md). Сейчас это **v0.3**: все 10 пластов с боссами-узорами атак, финальный босс Богомирон, бесконечная Изнанка с двойными боссами и Истинным Богомироном, четыре пленника с ветками прокачки, 6 героев, 64 предмета, реклама и покупки Яндекс Игр.

Стек: TypeScript + Vite + Canvas 2D, без движка. Пиксель-арт и звук генерируются кодом; единственная картинка - анимированный спрайт Богомирона (два листа по 17 кадров, вшиты в код как PNG). Сборка около 360 КБ (165 КБ gzip).

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173, реклама и покупки имитируются
npm test           # генерация этажей на 40 сидах для каждого пласта, бот проходит этаж
npm run build      # сборка в dist/
```

Параметры адреса для отладки: `?fastads` (тестовая реклама без задержки), `?debug` (объект `window.__game` в продакшен-сборке), `?platform=dev` (не грузить SDK Яндекса).

Управление: на телефоне плавающий джойстик (тяни палец в любом месте экрана) и кнопки справа; на ПК WASD или стрелки, пробел/E - способность героя, F - факел, Q - бомба, R - сканер, H - зелье, Esc - пауза. Упрись в стену - гном копает; меч бьёт сам, когда враг рядом.

## Публикация на Яндекс Играх

1. `npm run build`, затем заархивировать **содержимое** `dist/` (index.html в корне архива) и загрузить в [консоль](https://games.yandex.ru/console/).
2. SDK подключается сам с `/sdk.js` (так площадка требует для игр, загруженных архивом). Вне Яндекса игра автоматически переходит в тестовый режим.
3. В консоли создать товары с такими ID (все постоянные, не потребляются):
   - `no_ads` - Без рекламы
   - `starter_pack` - Набор новичка (300 слитков и золотая каска)
   - `golden_smelter` - Золотая плавильня (+50% слитков)
4. Лидерборд с техническим именем `depth` (рекорд глубины в метрах).
5. Remote Config, флаг `ad_cooldown`: минимальная пауза между полноэкранной рекламой в секундах (по умолчанию 150). Частоту дополнительно ограничивает сама площадка.

Где вызывается реклама:

- полноэкранная: спуск с привала на следующий этаж и выход из итогов в посёлок; не раньше первого подъёма с добычей и не чаще `ad_cooldown`;
- rewarded: «Второе дыхание» (встать с половиной здоровья), x2 слитков в итогах, ещё вариант предмета, бесплатное обновление лавки.

## RuStore

Игра собирается как веб-приложение, поэтому для Android её нужно обернуть (например, Capacitor) и заменить `src/platform/yandex.ts` на реализацию интерфейса `Platform` (`src/platform/types.ts`) для Android:

- платежи: RuStore Pay SDK (официально есть для Kotlin/Java, Unity, Godot, Defold; для обёртки нужен небольшой нативный плагин-мост);
- реклама: Yandex Mobile Ads SDK (полноэкранная, rewarded, баннер);
- сохранения: локальные (уже работают через localStorage WebView).

## Структура

```
src/
  config.ts           баланс
  core/               логика без отрисовки: сетка, генерация этажа, забег, характеристики, экономика, сохранения
  data/               пласты, руды, враги, герои, предметы, кирки и мечи, постройки
  game/               симуляция этажа и ИИ врагов, рендер, текстуры, звук, ввод, контроллер игры
  ui/                 HUD и экраны (DOM)
  platform/           Яндекс Игры и тестовая заглушка
tests/                генерация, бот для этажей и кампаний
```

## Баланс

`tests/bot.ts` - бот, который проходит этажи: копает к лестнице, по пути собирает видимую руду и сундуки, рубит врагов, спасает пленников, бьёт босса и уворачивается (прогноз опасности на 0.2-0.5 с: удары с неба, лучи, волны, зоны, снаряды, бомбы, метки).

```bash
SIM=1 SIM_OUT=sim.log npx vitest run tests/floor.test.ts        # забеги разными героями
SIM_META=1 SIM_RUNS=300 SIM_OUT=sim.log npx vitest run tests/floor.test.ts   # кампания: лифты, постройки, мастера
```

На v0.2 бот проходит этаж за 40-110 секунд, побеждает Червя в первом забеге примерно в 6 случаях из 10, а Голема примерно к 3-му забегу. Человек исследует комнаты и тратит на этаж 2-4 минуты.
